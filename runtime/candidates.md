# 待固化的重复工作流候选

新技能需求雷达。记录用户在对话里提到、但还没有对应技能的重复性工作流。**不是**待办清单，只是备忘——重复出现 ≥2 次时，下次相关对话里主动问一句"要不要固化成技能"。

| 模式描述 | 提到次数 | 最近提及 | 已建技能 |
|---|---|---|---|
| <!-- 例：每周把多处周报汇总成公司固定格式 | 2 | 2026-09-25 | 未建 --> |

规则：
- 用户出现"每周 / 每次 / 老是 / 又要 / 这个事我一直 / 以后都要"等重复信号、且没有对应技能时，追加一行；用户明确拒绝固化就删掉或标 `wontfix`。
- 用户确认要建后，走 Loop A，建成后在"已建技能"列填技能名。
- 本文件由 agent 在对话中维护，不做自动动作。
