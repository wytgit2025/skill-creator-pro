# 豆包工作环境

**特点：** 主 Agent 直接干活，不用调外部 API，零配置。字节跳动出品，有技能中心、连接器、工作伙伴三大功能。

## 技能系统
- 技能中心内置 200+ 官方技能
- 支持对话新建自定义技能（描述名称、触发场景、执行指令即可）
- 支持上传技能包
- 支持多 Agent 协同（工作伙伴）
- 支持连接器接入办公软件

## 跑测试
- 有并行能力就 spawn OrganizerAgent（子任务），带技能跑测试 + 基线同时跑对比
- 没有并行就自己一个一个跑（方案二）
- 结果直接在对话里展示给用户看
- 如果有 eval-viewer 可用，用 `--static` 模式生成独立 HTML 文件，通过 `present_files` 交付

## 优化描述
- 优先用 `scripts/run_loop.py` 跑自动优化循环（如果环境支持 Python 和模型 API）
- 或者你自己就是模型，根据失败案例手动迭代，2-3 轮就够了
- 手动迭代时，每次改完描述后，用 20 个触发测试查询重新评估触发率

## 交付
- 用 `present_files` 把技能文件夹或 `.skill` 文件交付给用户
- 或者直接告诉用户放到哪个目录里
- 用户也可以在豆包客户端的"技能"页面上传技能包导入
