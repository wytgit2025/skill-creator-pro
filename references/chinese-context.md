# 中文语境与国内合规

造面向中文用户的技能时，除了通用规范，还要注意下面这些。

## 中文写作类技能

不同文体的"好"标准不一样，别用同一套模板：

| 文体 | 特点 | 注意 |
|---|---|---|
| **公文/报告** | 严谨、客观、无主语也通顺 | 不要"我觉得"、不要感叹号、用"现将有关情况报告如下"这种固定起手式 |
| **周报/月报** | 简洁、结果导向 | 先结论后过程，用"完成了 X / 进行 Y / 计划 Z"三段式，别写散文 |
| **小红书文案** | 口语化、有 emoji、短段落 | 别用书面语，开头要钩子，结尾要引导互动 |
| **公众号文章** | 有观点、有节奏 | 别全是长句，每段别超过 3 行 |
| **商务邮件** | 客气但不啰嗦 | 中文邮件别写"Dear"，用"您好"；结尾别写"Best regards"，用"顺祝商祺"或"此致 敬礼" |

**通用坑：**
- 中文标点用全角（，。；：），不要半角混排
- 日期用 `2026年9月24日` 或 `2026-09-24`，别用 `Sep 24, 2026`
- 金额用 `¥` 或"元"，别默认 `$`
- 数字大的时候用中文单位（`1.2亿元` 不是 `120 million dollars`）

## 国内合规底线

技能如果要处理用户数据，特别是企业内部分发的，注意：

1. **数据不出境**——如果技能要调外部 API（包括海外 LLM），数据不能发到境外。国内用户的对话/文档默认留在国内。
2. **个人信息保护**——技能里如果要读用户数据（手机号、身份证、地址、聊天记录），：
   - 不要把这些数据写进日志
   - 不要把这些数据发到第三方 API
   - 处理完就删，不要持久化
3. **企业敏感数据**——财务、人事、客户名单：
   - 不要让技能把这些内容发到公网
   - 不要写进公开仓库
   - WorkBuddy 企业版会过沙箱扫描，含敏感操作的技能按最小权限写
4. **内容安全**——生成类技能别碰：政治敏感、色情、暴力、虚假宣传。国内平台比海外严，宁可保守。

**一句话：造中文技能时，假设用户的数据不能出境、不能外泄、不能出现在公开地方。**
